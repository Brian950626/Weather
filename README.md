# Weather

`weekcast`:預報任一地點未來一週的天氣,並說明每一天有多可信。

它不依賴單一模式,而是把三套全球系集預報(ECMWF、GEFS、AIFS,共 133 個成員)放在一起看:成員與模式意見一致時信心高,分歧時就把分歧講出來。
同時分析 250、500、700、850、925 hPa 各層的噴流、槽脊、水氣與平流,說明高空
如何影響地面的天氣。
方法來自對 [Tropical Tidbits](https://www.tropicaltidbits.com) 的研究,整理在
[docs/tropical-tidbits-notes.md](docs/tropical-tidbits-notes.md)。

## 線上預報

**<https://brian950626.github.io/Weather/>**

枋寮、台北、台中、高雄、花蓮的一週預報,每 6 小時自動更新。每天再拆成凌晨、上午、下午、
晚上四個時段,頁面下方有即時雷達回波(全球合成、日本氣象廳、中央氣象署三個來源,
在瀏覽器裡即時載入,每 5 分鐘更新)。同一份資料的 JSON 在
<https://brian950626.github.io/Weather/data.json>。

**查其他地點**:在頁面上方的搜尋欄輸入地名(例如「恆春」、「Tokyo」)或座標
(例如 `22.37,120.59`),同名的地點會列出來讓你選。選定後會在你的瀏覽器裡用同一份
分析程式即時計算,約 10–20 秒,結果與預設城市的內容完全相同;查過的地點會留在
分頁列,按 × 可移除。

網頁由 `.github/workflows/pages.yml` 在 GitHub Actions 上產生並發布到 GitHub Pages。
要換地點,修改該檔案裡的 `PLACES`。首次啟用需要在 repository 的
Settings → Pages 把 Source 設為 **GitHub Actions**,且這個流程要在 `main` 分支上才會執行。

在本機產生同樣的網頁:

```bash
python3 -m weekcast.site --out _site 台北 台中
```

## 使用

需要 Python 3.10 以上,不需安裝任何套件。

```bash
python3 -m weekcast 台北
```

```bash
python3 -m weekcast Tokyo --days 10
```

```bash
python3 -m weekcast --lat 23.47 --lon 120.96 --json
```

台灣各縣市與枋寮的地名已內建;其他鄉鎮可用「名稱@緯度,經度」(例如
`python3 -m weekcast 恆春@22.00,120.75`),國外地點用英文地名。

| 選項 | 說明 |
| --- | --- |
| `--days N` | 預報天數,1–16,預設 7 |
| `--lat` `--lon` | 直接指定座標 |
| `--models` | 只用部分模式,例如 `--models ecmwf_ifs025,gfs025` |
| `--json` | 輸出 JSON |
| `--save-raw PATH` | 把原始資料存成 `.json` 或 `.json.gz` |
| `--from-file PATH` | 改讀存下的原始資料,不連網 |
| `--no-upper` | 不做高空分析(少抓兩次資料,比較快) |
| `--no-history` | 不記錄、也不比較先前的預報 |

```
11/15 日  西 40    上空 39    -0.6  槽前(槽在西 14°)  5844       50%      15°C 88% 西 4    -0.8  北 2    26

• 槽線:500 hPa 槽線在 11/16 一 到 11/17 二 之間通過,通過前高空吹偏南風、較易有雨,通過後轉偏北風。
• 11/15 日:水氣只在低層、中層乾燥,若有雨是低雲的淺層降雨,雨量有限(…);降雨機率雖有 87%,雨量不大(中位數 5 mm)。
```

報表有七個部分:

- **逐日表格**:中位數與 10–90% 範圍、降雨機率(日雨量達 1 mm 的成員比例)、信心。
- **時段預報**:每天四個 6 小時時段的氣溫、天氣與降雨機率。越後面的日子,時段的
  可信度下降得比整天快(鋒面晚到半天,整天的預報仍對,時段卻會錯開)。
- **重點**:冷暖變化、哪幾天有雨、大雨與強風風險。
- **天氣型態**:從海平面氣壓、850 hPa 溫度、500 hPa 高度的變化判斷鋒面、冷空氣、
  高空脊槽,解釋地面天氣為什麼變。
- **高空分析**:逐日列出各層的狀況,再用「舉升、水氣、不穩定」三種成分研判,
  並和地面的降雨機率對照(詳見下節)。
- **不確定性**:信心不高的日子,各模式各自怎麼說。
- **與上次預報比較**:距離上次執行超過 5 小時後才會出現,列出預報修正了多少。
  紀錄存在 `~/.cache/weekcast/`。

## 高空分析看什麼

| 層 | 看什麼 | 對地面的意義 |
| --- | --- | --- |
| 250 hPa | 噴流軸的位置與強度、高層輻散 | 高層空氣流出(輻散)會帶動下方空氣上升 |
| 500 hPa | 槽線、脊線相對測站的位置與移動,副熱帶高壓(5880 m) | 槽前上升、易有雨;槽後與脊下沉、穩定 |
| 700 hPa | 中層濕度 | 中層夠濕雲才能長高;乾的話只有淺層降雨 |
| 850 hPa | 溫度、濕度、風、冷暖平流 | 暖平流抬升並增溫;冷平流下沉並降溫 |
| 925 hPa | 低層風與溫度 | 淺層冷空氣(如東北季風)與迎風面的水氣來源 |
| 綜合 | K 指數(850、700、500 hPa) | 30 以上容易有雷雨 |

槽脊與噴流要靠水平分布才找得到,所以除了測站上空,還會抓一個十字剖面:沿測站
緯度往東西各 40°(找 500 hPa 槽線)、沿測站經度往南北各 20°(找 250 hPa 噴流軸),
每 5° 一點。南北半球與熱帶東風帶都有對應的處理。

## 雷達與預報怎麼搭配

| 想知道 | 看哪裡 |
| --- | --- |
| 接下來 1–3 小時會不會下雨 | 即時雷達回波:雨現在在哪、往哪移動 |
| 今天到後天的上午或下午 | 時段預報 |
| 三天以後 | 逐日預報與信心分數;時段只當參考 |

雷達圖只在網頁上提供(命令列沒有),資料直接由瀏覽器向各來源取得,不經過這個
repository。

## 資料來源與限制

資料來自 [Open-Meteo Ensemble API](https://open-meteo.com/en/docs/ensemble-api)
(免費、免金鑰,有每日用量上限,非商業使用)。

- 溫度是模式格點值,沒有用測站觀測校正,山區與海邊誤差較大。
- 只看單點,看不到颱風或鋒面的位置。有颱風威脅時請以中央氣象署等官方警報為準。
- 信心分數與高空研判都是經驗法則,不是驗證過的機率。
- 高空分析只有 ECMWF 的兩套系集可用(其他模式不提供氣壓層資料),水平梯度以
  5° 間距估算,只能代表綜觀尺度;噴流軸超出南北 20° 時會標示「20°+」。
- 午後雷陣雨這類小尺度對流,全球系集解析不了。
